# YouGile Integration — Obsidian Plugin

Плагин для Obsidian, интегрирующий YouGile (канбан-доски, задачи, чаты) прямо внутри редактора.

## Возможности

- **Задачи**: список, фильтры, дерево подзадач, чаты, inline-создание, дедлайны
- **Документы**: таблица, детали, замечания, связанные документы, CSV/HTML-экспорт
- **Письма**: реестр исх./вх. писем, AI-чат (RAG по письмам), DOCX-экспорт по шаблону, HTML/CSV-экспорт
- **Календарь**: мероприятия на месяц, фильтр по задачам-документам, привязка к материнской задаче, автозавершение родителя
- **Дашборд**: 4 графика ApexCharts, метрики, фильтры (проект, колонка, исполнитель, даты, подзадачи, дедлайны), экспорт JPG/CSV
- **Предложения**: таблица, создание/редактирование, детальный просмотр, завершение, приоритеты, офлайн-очередь
- **Контакты**: таблица, создание/редактирование, детали, QR-код (vCard, красный, 250×250), локальная JSON БД, синхронизация с YouGile
- **Гибкие настройки**: каждый модуль включается/отключается отдельно, проекты и доски выбираются через dropdown
- **Офлайн-режим**: очередь действий при отсутствии сети, автосинхронизация
- **Кэширование**: yougile_cache.json для проектов, досок, колонок, пользователей, задач

## Установка

1. Скопируйте папку в `<хранилище>/.obsidian/plugins/yougile-tntn/`
2. Включите плагин: Настройки → Сторонние плагины → YouGile Integration
3. Откройте настройки плагина, введите логин, пароль и companyId, нажмите «Получить ключ»
4. Используйте ribbon-иконки или команды (`Ctrl+P` → «YouGile: ...»)

Подробная инструкция — в файле [`instruction.md`](instruction.md).

## Настройки

Шесть складных блоков с переключателями модулей:

| Блок | Toggle | Поля |
|------|--------|------|
| Базовые настройки | нет | companyId, логин, пароль, API-ключ, доска |
| Календарь | да | проект, доска |
| Документы | да | проект, доска |
| Письма | да | проект, доска, путь БД, автор, AI (ключ/URL/модель/промпт), DOCX (шаблон/папка) |
| Контакты | да | проект, доска, путь БД |
| Дашборд | да | без полей |

## Требования

- Obsidian v1.11.4+
- Учётная запись YouGile (https://yougile.com)
- Desktop-версия Obsidian

## Сборка

```bash
npm install
npm run build    # production
npm run dev      # hot-reload
```
