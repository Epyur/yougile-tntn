## 1. Начало работы

1. Скачайте архив **plugins.zip**
2. Сохраните его в папку `.obsidian/` вашего хранилища Obsidian и распакуйте (файлы должны оказаться в `.obsidian/plugins/yougile-tntn/` и `.obsidian/plugins/updater/`)
3. В Obsidian: **Настройки → Сторонние плагины → YouGile TN TN** → включите, затем включите **YouGile TN TN Updater**
4. Откройте настройки плагина (шестерёнка → **YouGile Integration**)
5. Заполните **Базовые настройки** (ID компании уже указан по умолчанию, при необходимости замените на свой):
   - **ID компании** — в YouGile нажмите `Ctrl+Alt+Q` / `Cmd+Option+Q`, скопируйте ID
   - **Логин** — email от аккаунта YouGile
   - **Пароль** — пароль от YouGile
6. Нажмите **«Получить ключ»** — API-ключ сохранится защищённо
7. В разделах **Календарь**, **Документы**, **Письма** и **Контакты** уже выбраны стандартные проекты и доски (подставятся автоматически при первом открытии). При необходимости выберите свои проект и доску из выпадающего списка.
8. Для работы AI-помощника и презентаций настройте **Письма → AI помощник**: API-ключ, URL API и модели LLM.

После настройки появятся иконки на левой ленте (риббоне). Нажмите на любую, чтобы открыть панель.

> **Базы данных.** Плагин хранит все данные в папке `yourbase/` относительно корня хранилища: `yourbase/yougile_cache.json` (кэш проектов/досок/колонок/пользователей/задач), `yourbase/mailer_data.json` (письма), `yourbase/contacts_data.json` (контакты), `yourbase/presentations_data.json` (презентации). Пути жёстко прописаны в коде и не настраиваются. Рекомендуется добавить `yourbase/` в `.gitignore`.

> **Обновления.** Вместе с основным плагином устанавливается **YouGile TN TN Updater** — вспомогательный плагин, который автоматически проверяет наличие новой версии при каждом запуске Obsidian. Если обновление найдено, он самостоятельно скачивает и устанавливает файлы, после чего перезапускает основной плагин. Вмешательство пользователя не требуется. При обновлении показывается окно со списком изменений.

## 2. Настройки плагина

Настройки разделены на **8 складных блоков**. Название блока — заголовок со стрелкой ▼/▶; клик по нему сворачивает/разворачивает блок. Во все модули (кроме Дашборда) внесены стандартные проект и доска, а в базовые настройки — ID организации. При необходимости вы можете изменить их на свои.

### 2.1 Базовые настройки

Всегда включён. Поля:

| Поле | Описание |
|------|----------|
| ID компании | По умолчанию указан ID организации, при необходимости замените на свой (скопировать в YouGile: `Ctrl+Alt+Q`) |
| Логин | Email от YouGile |
| Пароль | Хранится в защищённом хранилище Obsidian |
| Получить API Key | Отправляет логин/пароль на YouGile, сохраняет ключ |
| ID доски по умолч. | Доска, используемая если не указана другая (опционально) |

### 2.2 Включение/отключение модулей

У блоков **Календарь**, **Документы**, **Письма**, **Контакты**, **Дашборд**, **LPI** и **Презентации** справа от заголовка есть чекбокс ✓. Когда чекбокс снят:
- Вьюха модуля не регистрируется (нельзя открыть)
- Ribbon-иконка скрывается
- Команды модуля не выполняются

**Модуль Предложения** всегда включён и не имеет toggle.

### 2.3 Календарь

По умолчанию выбран проект «Расписание мероприятий» и доска «Мероприятия». При необходимости выберите свой проект и доску из выпадающего списка.

После настройки появится ribbon-иконка с календарём и команда **«YouGile: Открыть расписание мероприятий»**.

### 2.4 Документы

По умолчанию выбран проект «Документы со сроками актуализации» и доска «Документы». При необходимости выберите свои проект и доску.

После настройки появится ribbon-иконка с документом и команда **«YouGile: Открыть документы»**.

### 2.5 Письма

Самый насыщенный блок с несколькими подразделами. По умолчанию выбран проект «Письма технической дирекции» и доска «Письма Технической дирекции». При необходимости выберите свои.

**Основные настройки:**
- Проект и доска для писем
- Автор по умолчанию — ФИО для новых писем

**AI помощник:**
- API ключ — для OpenAI-совместимого API (например, ask.chadgpt.ru)
- URL API — адрес эндпоинта
- **Модели LLM (до 5)** — список названий моделей (например, `deepseek-v4-pro`, `deepseek-v4-flash`). Все модели используют **один** API-ключ и URL.
- **Модель по умолчанию** — какая из подключённых моделей используется по умолчанию (в чате писем и в презентациях её можно переключить вручную)
- Системный промпт — инструкция для AI (по умолчанию на русском, эксперт по пожарной безопасности)

**Экспорт в DOCX:**
- Путь к шаблону — .docx файл с плейсхолдерами `{{Номер}}`, `{{Текст}}` и т.д.; кнопка «Обзор» для выбора из файлов Obsidian
- Папка экспорта — куда сохранять сгенерированные DOCX

### 2.6 Контакты

По умолчанию выбран проект «Контакты дирекции» и доска «Контакты». При необходимости измените на свои.

После настройки появится ribbon-иконка с пользователем и команда **«YouGile: Открыть контакты»**.

### 2.7 Дашборд

Без полей, только чекбокс включения/отключения. При включении появляется ribbon-иконка и команда.

### 2.8 LPI

По умолчанию выключен. Включить: Настройки → YouGile Integration → блок LPI → чекбокс. Поля блока:
- **Путь к SQLite БД** — кнопка «Обзор...» для выбора файла базы LIMS
- Проект, доска, колонка — выпадающие списки

После включения появляется ribbon-иконка с пламенем и команда **«YouGile: Открыть LPI»**.

### 2.9 Презентации

По умолчанию включён. Поля блока:
- Кнопка **«Открыть»** — открывает папку с шаблонами и дизайн-скилом
- **Шаблон по умолчанию** — выпадающий список (встроенный «Технониколь» + пользовательские шаблоны)

После включения появляется ribbon-иконка с презентацией и команда **«YouGile: Открыть презентации»**.

## 3. Панель задач

Открывается через ribbon-иконку со списком или команду **«YouGile: Показать задачи»**.

- **Список задач** — все задачи выбранного проекта/доски, можно фильтровать по колонке, исполнителю, статусу, тексту
- **Дерево подзадач** — вложенные задачи с переходом по клику
- **Inline-детали** — клик по задаче открывает подробную информацию справа без модального окна
- **Редактирование** — кнопка «Редактировать» в деталях задачи (title, description, проект/доска/колонка, исполнители, дедлайн)
- **Дедлайн** — индикатор цвета (зелёный >3 дня / оранжевый 1-3 дня / красный <1 дня или просрочен)
- **Чаты** — вкладка с чатами; в деталях задачи кнопки «Перейти в чат» / «Создать чат»
- **Создать задачу** — inline-форма: выбор проекта → доски → колонки, email исполнителей, дедлайн
- **Офлайн** — при отсутствии сети действия ставятся в очередь и выполняются при подключении
- **Индикатор синхронизации** — ✅ или ⚠

---

## 4. Модуль Документы

Открывается через ribbon-иконку с документом или команду.

- **Таблица документов** — колонки: №, название, тип, срок, куратор, файлы, связанные документы
- **Детали** — клик по строке открывает подробную информацию в правой панели
- **Создание документа** — inline-форма со всеми полями. Ссылка на документ должна начинаться с `https://kb.tn.ru/file`
- **Замечания** — форма добавления замечания; таблица замечаний с № п/п и автором (email)
- **Связанные документы** — ссылки на другие документы
- **Экспорт CSV** — файл в папку `Экспорт` с BOM и разделителем `;`
- **Экспорт HTML** — копирование таблицы в буфер обмена

## 5. Модуль Письма

Открывается через ribbon-иконку с конвертом или команду.

- **Таблица писем** — столбцы: № исх., дата, приложение, тема, содержание; сортировка по дате
- **Фильтры** — по дате (период), автору, колонке, текстовый поиск (с задержкой 3 сек)
- **Создание письма** — форма с полями: номер, дата, тема, содержание, приложение, файлы
- **Редактирование** — двойной клик по строке открывает форму редактирования
- **Файлы** — прикрепляются к письму и загружаются на YouGile
- **Экспорт HTML** — копирование таблицы в буфер обмена
- **Экспорт CSV** — файл в папку `Экспорт`

## 6. AI-помощник по письмам

Доступен внутри модуля Письма (кнопка AI).

- Задайте вопрос по содержимому писем — AI выполнит RAG-поиск по локальной базе
- Можно загрузить файл (изображение, PDF, DOCX, TXT) — AI прочитает и ответит по его содержимому
- Кнопка **«Создать письмо»** в ответе AI — автоматически заполняет форму создания письма на основе ответа
- **Выбор модели** — в шапке чата дропдаун «🤖 Модель»: можно переключить модель для текущего диалога (список из настроек; «По умолчанию» — модель, заданная в настройках)

Требуется настроить API-ключ, URL и модели LLM в настройках плагина (блок Письма → AI помощник).

## 7. Экспорт в DOCX

Генерирует DOCX-файл письма по шаблону:

1. **Шаблон** — .docx файл с плейсхолдерами `{{Номер}}`, `{{Дата}}`, `{{Тема}}`, `{{Содержание}}`, `{{Текст}}`, `{{Приложение}}`, `{{Компания}}`, `{{Адрес}}` и т.д.
2. **Без шаблона** — fallback-генерация через библиотеку `docx` (стили, таблицы, изображения)

Изображения из письма вставляются в документ.

Путь к шаблону и папка экспорта настраиваются в блоке Письма → Экспорт в DOCX.

## 8. LPI (Лаборатория пожарных испытаний)

Открывается через ribbon-иконку с пламенем или команду **«YouGile: Открыть LPI»**. Включить модуль: Настройки → YouGile Integration → блок LPI (задать путь к SQLite БД).

- **Таблица заявок** — колонки: индикатор, №, материал, дата создания, статус (активна/завершена по дате протокола), дата протокола, результат испытания, оценка соответствия, действия
- **Действия в таблице** — 📥 (загрузить заявку из SQL) и 📤 (отправить заявку в YouGile)
- **Фильтры** — по дате создания и статусу
- **Синхронизация с YouGile** — автоимпорт новых заявок; кнопки «📤» отправляют заявки в YouGile; статус определяется по наличию даты протокола
- **Детали** — клик по строке: все поля заявки (заказчик, ЕКН, толщина, группа горючести, температура дыма и т.д.), редактирование формы с сохранением в YouGile
- **Дашборд** (кнопка «Дашборд» в шапке):
  - Графики: статусы заявок (donut), поступление/завершение по месяцам (bar), оценка соответствия (donut), результаты испытаний (donut), топ продуктов (bar)
  - Фильтры: дата создания заявки (с/по), дата протокола (с/по), чекбоксы «Серийная продукция» / «Опытная продукция», выбор продуктов
- **Schema Browser / Query Runner** — просмотр схемы SQLite БД и выполнение запросов

## 9. Календарь мероприятий

Открывается через ribbon-иконку с календарём или команду.

- **Месячный календарь** — просмотр задач на месяц с цветовой индикацией статуса
- **Детали дня** — клик по дню открывает список событий
- **Создание мероприятия** — форма с полями: название, место, аудитория, ответственный (email), дата/время, описание
- **Материнская задача** — при создании можно выбрать родительскую задачу (поиск по всем проектам/доскам через автодополнение):
  - Новая задача мероприятия автоматически становится подзадачей родителя (добавляется в `subtasks`)
  - Чекбокс **«Завершить материнскую задачу при завершении мероприятия»**
  - **Проверка дедлайна** — если дата мероприятия выходит за пределы дедлайна материнской задачи, показывается предупреждение
- **Отчёт о мероприятии** — форма с текстом и файлами, после отправки задача отмечается завершённой
- **Фильтры** — чекбоксы колонок, переключение «Все / Мероприятия / Документы»
- **Редактирование** — кнопка ✏️ в деталях события

## 10. Дашборд

Открывается через ribbon-иконку с графиком или команду.

- **4 графика** ApexCharts:
  - «Задачи по колонкам» (donut)
  - «Статус задач» (bar)
  - **«Динамика озадачивания»** (area) — две серии: «Поступило задач» / «Задач решено», пунктирные отсечки дедлайнов. Завершённые задачи учитываются по **фактической дате завершения** (из YouGile), а не по дате создания
  - «Дедлайны» (bar)
- **Метрики** — счётчики: всего задач, просрочено, завершено, с дедлайном
- **Фильтры** (с подписями над каждым):
  - Проект, доска, колонка, исполнитель — выпадающие списки
  - Период дат — поля `с ... по ...` (учитывается дата создания **или** завершения задачи)
  - **«Учитывать подзадачи»** (чекбокс) — исключает задачи-подзадачи
  - **«Показать дедлайны»** (чекбокс) — пунктирные линии на графике динамики
- **Экспорт JPG** (scale 2x) — каждый график отдельно или все сразу
- **Экспорт CSV** — таблица задач в файл (включая колонки «Создана» и «Завершена»)

## 11. Модуль Предложения

Открывается через ribbon-иконку с лампочкой или команду.

- **Таблица предложений** — колонки: колонка, суть, проблема, ожидаемый эффект, приоритет, автор, статус
- **Создание** — форма с полями: колонка (Предложения / Ошибки), суть предложения, проблема (Зачем?), ожидаемый эффект, приоритет (Критичный / Высокий / Средний / Просто идея). Автор определяется автоматически по логину.
- **Детали** — клик по строке открывает подробный просмотр
- **Редактирование** — кнопка «Редактировать» в деталях, после сохранения показывается ответ сервера
- **Завершение** — кнопка «Завершить» в деталях предложения
- **Офлайн-очередь** — при отсутствии сети создание/изменение ставится в очередь

Проект и доска жёстко заданы: проект «Развитие плагина», доска «Предложения», колонки «Предложения» и «Ошибки».

---

## 12. Модуль Контакты

Открывается через ribbon-иконку с пользователем или команду.

- **Таблица контактов** — колонки: имя, телефон, email, организация, должность; поиск по тексту с задержкой 300мс
- **Фильтр по колонкам** — чекбоксы «Тип организации» для отбора контактов
- **Создание контакта** — форма с полями: тип организации (выбор колонки доски), имя, телефон, email, организация, должность, примечание
- **Детальный просмотр** — клик по строке открывает подробную информацию и QR-код контакта (vCard, красный цвет, 250×250px)
- **Редактирование** — кнопка «Редактировать» в деталях
- **Синхронизация** — контакт сохраняется локально в `yourbase/contacts_data.json` и дублируется в YouGile как задача с `completed: true`; `Тип организации` определяется по колонке задачи
- **Офлайн-режим** — при отсутствии сети создание/обновление ставится в очередь

## 13. Модуль Презентации

Открывается через ribbon-иконку с презентацией или команду **«YouGile: Открыть презентации»**.

### Создание презентации

1. Нажмите **«🆕 Новая презентация»** и заполните анкету: тема, аудитория, цель, ключевые сообщения, тон, структура, докладчик, телефон/email, дата, число слайдов, кикер, при необходимости загрузите иллюстрации.
2. По умолчанию запускается **мозговой штурм** — LLM задаёт уточняющие вопросы, чтобы собрать детали (можно «⏭ Пропустить»).
3. После штурма начинается генерация. **Элемент сразу появляется в списке** с мигающим индикатором «Генерация…»; по завершении превращается в готовую презентацию. При ошибке показывается статус с кнопкой «🔁 Перегенерировать».

### Список презентаций

В строке презентации доступны кнопки:
- **👁 Предпросмотр** — открыть HTML-презентацию в окне
- **🖨 PDF** — предпросмотр для печати в PDF
- **📷 Изображения** — загрузить иллюстрации и **фоны слайдов** (титул, контентные слайды, финальный) с настройкой затемнения
- **⚙ Показ** — настройки показа (см. ниже)
- **🔁 Перегенерировать** — заново сгенерировать по анкете
- **💾 Экспорт HTML** — сохранить самодостаточный HTML-файл в `Экспорт/Презентации/`
- **📤 В чат YouGile** — выбрать задачу и отправить презентацию в её чат (файл-ссылка)
- **🗑 Удалить**

### Шаблоны

- Оформление задаётся шаблонами **TemplateSpec** (JSON) в папке `yourbase/presentation_templates/`
- Встроенный шаблон «Технониколь»; пользовательские шаблоны имеют приоритет
- **«🎨 Новый шаблон»** — извлечение шаблона из примера презентации через LLM

### Показ (режим «Слайды»)

- Кнопки панели: **Лендинг** (вертикальный список слайдов), **Слайды** (полноэкранная демонстрация), **◀ ▶**, **⛶ Экран** (полный экран), **▶ Авто / ⏸ Стоп** (автопоказ), **🖨 Печать / PDF**
- **Клавиатура**: →/↓/PageDown/Space — вперёд, ←/↑/PageUp — назад, Home/End — первый/последний, `F` — полный экран
- **Мышь**: левый клик по слайду — вперёд, правый клик — назад
- **Свайп** на тач-экране: влево/вправо
- **Автопоказ** — переключение по времени (интервал задаётся в «⚙ Показ»)
- **Эффекты перехода** — Fade, Fade+сдвиг, без эффекта
- **Прогресс-бар** внизу экрана (включается/выключается в «⚙ Показ»)
- **Зацикливание** — после последнего слайда снова первый
- **В полном экране** панель управления скрывается; выход — `F` или `Esc`
- **«⚙ Показ»** — настройки: интервал автопереключения (сек, 0 = выкл), эффект перехода, прогресс-бар, зацикливание. Дефолты берутся из шаблона.

### Печать PDF

Откройте **🖨 Печать / PDF** → в диалоге печати выберите «Сохранить как PDF», бумагу 16:9 / «Презентация» и поля «Нет» — слайды займут весь лист без отступов.

## 14. Экспорт данных

| Формат | Где доступен | Как работает |
|--------|-------------|--------------|
| HTML | Письма, Документы, Презентации | Копирует таблицу в буфер обмена / сохраняет файл |
| CSV | Письма, Документы, Дашборд | Сохраняет файл в папку `Экспорт` с BOM, разделитель `;` |
| DOCX | Письма | Генерирует DOCX по шаблону или автоматически |
| JPG | Дашборд | Сохраняет скриншот дашборда (scale 2x) |
| PDF | Презентации | Печать HTML-презентации без полей |
