Этап 0: Исследование и Подготовка
Прежде чем писать код, нужно понять, с чем мы работаем.

Изучение API YouGile:

Аутентификация: В API YouGile используются ключи компании (в заголовке Authorization: Bearer <KEY>) и персональные ключи (в заголовке Authorization: Bearer <KEY>). Нам нужен либо один, либо другой. Персональный ключ удобнее для индивидуального плагина.

Основные сущности: Изучи методы для работы с досками, колонками, задачами.

Методы для MVP (Минимально жизнеспособный продукт):

GET /api-v2/tasks - получить список задач.

POST /api-v2/tasks - создать задачу.

GET /api-v2/tasks/{id} - получить детали задачи.

Формат данных: Обрати внимание на JSON-структуры запросов и ответов.

Планирование функционала (MVP):

Настройки: Возможность ввести API-ключ и, возможно, ID доски по умолчанию.

Команды (Command Palette):

YouGile: Создать задачу — открывает модальное окно для ввода названия и описания.

YouGile: Список моих задач — выводит список задач из YouGile в отдельную вкладку/панель.

Представление (View): Боковая панель (Sidebar View) для отображения списка задач.

Этап 1: Настройка проекта и окружения
Создание репозитория:

Создай новую директорию, например, obsidian-yougile-plugin.

Инициализируй Git: git init.

Создай файл .gitignore (добавь туда node_modules, main.js, *.js.map, .obsidian/ при локальной разработке).

Инициализация npm:

npm init -y

Установи типы Obsidian API: npm install --save-dev obsidian

Установи TypeScript: npm install --save-dev typescript

Создай tsconfig.json со стандартными настройками для Obsidian (цель ES6, поддержка ESNext, включение строгого режима).

Настройка сборки:

Используй esbuild (как в примере плагина Obsidian) для быстрой сборки.

Создай скрипт npm run dev для сборки в режиме разработки и npm run build для продакшена.

Создай manifest.json. Пример:

json
{
  "id": "obsidian-yougile",
  "name": "YouGile Integration",
  "version": "0.1.0",
  "minAppVersion": "1.1.0",
  "description": "Интеграция с YouGile для управления задачами.",
  "author": "Твое Имя",
  "isDesktopOnly": true
}

Этап 3: Пошаговая реализация кода
1. Точка входа (main.ts)
Класс YouGilePlugin должен наследоваться от Plugin.

Метод onload():

Загрузка данных (настроек) плагина.

Инициализация YouGileClient с передачей API-ключа из настроек.

Добавление вкладки настроек (addSettingTab).

Регистрация кастомного представления (registerView для панели задач).

Инициализация и добавление команд из модуля commands.ts.

Добавление иконки на ленту для открытия панели задач.

Метод onunload():

Освобождение ресурсов, отписка от событий.

2. Клиент для API (api/client.ts)
Создай класс YouGileClient с конструктором, принимающим API-ключ.

Инкапсулируй логику HTTP-запросов.

Приватный метод request():

Использует fetch или requestUrl (рекомендация Obsidian для обхода CORS).

Принимает метод, эндпоинт и тело запроса.

Добавляет заголовки Authorization: Bearer ${apiKey} и Content-Type: application/json.

Обрабатывает ошибки (неверный ключ, таймаут, проблемы с API).

Публичные методы:

getTasks(filter?): Запрос на получение задач.

createTask(title, description, columnId?): Создание задачи.

getTaskById(id): Получение одной задачи.

3. Настройки (ui/settings-tab.ts)
Создай интерфейс YouGileSettings с полями:

apiKey: string

defaultBoardId: string (опционально)

Класс YouGileSettingTab (наследуется от PluginSettingTab):

display(): Отрисовка полей ввода.

Поле для API-ключа (с маскированием).

Поле для ID доски по умолчанию.

Кнопка "Проверить соединение" (опционально).

4. Представление "Список задач" (ui/tasks-view.ts)
Класс TasksView наследуется от ItemView.

getViewType(): возвращает "yougile-tasks-view".

getDisplayText(): возвращает "YouGile: Задачи".

getIcon(): можно использовать "list-todo" или загрузить свою SVG-иконку.

Логика onOpen():

Создать контейнер в this.contentEl.

Добавить кнопку "Обновить".

Добавить элемент-контейнер для списка задач.

Вызвать this.loadTasks().

Метод loadTasks():

Установить статус загрузки (спиннер).

Вызвать this.plugin.client.getTasks().

Полученный массив задач преобразовать в HTML/DOM-элементы.

Для каждой задачи: чекбокс, название (кликабельное), колонка/доска.

Обработать возможные ошибки (показать уведомление Notice).

Обновление: Добавь метод для перерисовки и используй this.registerInterval для автообновления (например, раз в 5 минут).

5. Команды (commands.ts)
Функция registerCommands(plugin).

Команда "Создать задачу":

Проверяет наличие API-ключа в настройках.

Открывает CreateTaskModal.

После подтверждения вызывает plugin.client.createTask(...).

Показывает new Notice('Задача создана').

Команда "Обновить список задач":

Принудительно вызывает tasksView.loadTasks().

6. Модальное окно создания задачи (ui/create-task-modal.ts)
Класс CreateTaskModal наследуется от Modal.

constructor принимает plugin и необязательный columnId.

Метод onOpen():

Заголовок "Новая задача YouGile".

Поле ввода "Название задачи" (обязательное).

Поле ввода "Описание" (textarea).

Выпадающий список для выбора колонки/доски (опционально для MVP, сложнее).

Кнопки "Создать" и "Отмена".

Логика кнопки "Создать": валидация, вызов API, закрытие окна.

Этап 4: Сборка и локальное тестирование
Сборка: Запусти npm run dev. Твой main.js, manifest.json и styles.css должны появиться в корневой папке проекта.

Создание символьной ссылки (Symlink):

Найди путь к хранилищу Obsidian (.obsidian/plugins/).

Вместо копирования файлов при каждом изменении создай жесткую или символьную ссылку на папку проекта:

Windows (от администратора): mklink /D "путь_к_хранилищу\.obsidian\plugins\obsidian-yougile" "путь_к_папке_проекта"

macOS/Linux: ln -s /полный/путь/к/проекту /полный/путь/к/хранилищу/.obsidian/plugins/obsidian-yougile

Тестирование:

Открой консоль разработчика в Obsidian (Ctrl+Shift+I).

Перезагрузи плагины в Obsidian.

Включи плагин в настройках.

Проверь каждую команду, модальное окно и панель. Исправляй ошибки.

Этап 5: Расширение функционала (после MVP)
После того, как базовое создание и чтение задач заработает, можно добавить:

Редактирование и удаление: Из модального окна или контекстного меню в представлении задач.

Синхронизация с заметками: Команда "Прикрепить задачу к заметке" (сохранять ID задачи в frontmatter заметки).

Автоматическое создание задачи из чекбокса: Сканировать заметки на чекбоксы с определенным тегом (например, #yougile).

Отображение полной карточки: При клике на задачу открывать панель с полным описанием, сроками и чек-листами.

Кэширование: Хранить полученные задачи локально, чтобы не делать запрос при каждом открытии панели.
