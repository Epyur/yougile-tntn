## 1. Начало работы

1. Установите плагин в папку `.obsidian/plugins/yougile-tntn/`
2. В Obsidian: **Настройки → Сторонние плагины → YouGile Integration** → включите
3. Откройте настройки плагина (шестерёнка → **YouGile Integration**)
4. Заполните **Базовые настройки**:
   - **ID компании** — в YouGile нажмите `Ctrl+Alt+Q` / `Cmd+Option+Q`, скопируйте ID
   - **Логин** — email от аккаунта YouGile
   - **Пароль** — пароль от YouGile
5. Нажмите **«Получить ключ»** — API-ключ сохранится защищённо
6. Выберите проект и доску для каждого нужного модуля

После настройки появятся иконки на левой ленте (риббоне). Нажмите на любую, чтобы открыть панель.

## 2. Настройки плагина

Настройки разделены на 5 складных блоков. Название блока — заголовок со стрелкой ▼/▶; клик по нему сворачивает/разворачивает блок.

### 2.1 Базовые настройки

Всегда включён. Поля:

| Поле | Описание |
|------|----------|
| ID компании | Скопировать в YouGile: `Ctrl+Alt+Q` |
| Логин | Email от YouGile |
| Пароль | Хранится в защищённом хранилище Obsidian |
| Получить API Key | Отправляет логин/пароль на YouGile, сохраняет ключ |
| ID доски по умолч. | Доска, используемая если не указана другая (опционально) |

### 2.2 Включение/отключение модулей

У блоков **Календарь**, **Документы**, **Письма** и **Дашборд** справа от заголовка есть чекбокс ✓. Когда чекбокс снят:
- Вьюха модуля не регистрируется (нельзя открыть)
- Ribbon-иконка скрывается
- Команды модуля не выполняются

Это удобно, если вы используете только часть функционала и не хотите загружать интерфейс лишними панелями.

### 2.3 Календарь

Выберите проект и доску для календаря мероприятий. В колонках этой доски должны быть задачи с датами.

После настройки появится ribbon-иконка с календарём и команда **«YouGile: Открыть расписание мероприятий»**.

### 2.4 Документы

Выберите проект и доску для документов. Задачи с типом «документ» отобразятся в таблице модуля.

После настройки появится ribbon-иконка с документом и команда **«YouGile: Открыть документы»**.

### 2.5 Письма

Самый насыщенный блок с тремя подразделами:

**Основные настройки:**
- Проект и доска для писем
- Путь к базе писем — файл `mailer_data.json` (можно указать свой путь)
- Автор по умолчанию — ФИО для новых писем

**AI помощник:**
- API ключ — для OpenAI-совместимого API (например, ask.chadgpt.ru)
- URL API — адрес эндпоинта
- Модель — название LLM
- Системный промпт — инструкция для AI (по умолчанию на русском, эксперт по пожарной безопасности)

**Экспорт в DOCX:**
- Путь к шаблону — .docx файл с плейсхолдерами `{{Номер}}`, `{{Текст}}` и т.д.; кнопка «Обзор» для выбора из файлов Obsidian
- Папка экспорта — куда сохранять сгенерированные DOCX

### 2.6 Дашборд

Без полей, только чекбокс включения/отключения. При включении появляется ribbon-иконка и команда.

## 3. Панель задач

Открывается через ribbon-иконку со списком или команду **«YouGile: Показать задачи»**.

- **Список задач** — все задачи выбранного проекта/доски, можно фильтровать по колонке, исполнителю, статусу, тексту
- **Дерево подзадач** — вложенные задачи с переходом по клику
- **Inline-детали** — клик по задаче открывает подробную информацию справа без модального окна
- **Дедлайн** — индикатор цвета (зелёный >3 дня / оранжевый 1-3 дня / красный <1 дня или просрочен)
- **Чаты** — вкладка с чатами; в деталях задачи кнопки «Перейти в чат» / «Создать чат»
- **Создать задачу** — inline-форма: выбор проекта → доски → колонки, email исполнителей, дедлайн
- **Офлайн** — при отсутствии сети действия ставятся в очередь и выполняются при подключении
- **Индикатор синхронизации** — ✅ или ⚠

## 4. Модуль Документы

Открывается через ribbon-иконку с документом или команду.

- **Таблица документов** — колонки: №, название, тип, срок, куратор, файлы, связанные документы
- **Детали** — клик по строке открывает подробную информацию в правой панели
- **Создание документа** — inline-форма со всеми полями
- **Замечания** — форма добавления замечания (поля + файл); таблица замечаний с № п/п и автором (email)
- **Связанные документы** — ссылки на другие документы
- **Экспорт CSV** — файл в папку `Экспорт` с BOM и разделителем `;`
- **Экспорт HTML** — копирование таблицы в буфер обмена

## 5. Модуль Письма

Открывается через ribbon-иконку с конвертом или команду.

- **Таблица писем** — столбцы: № исх., дата, приложение, тема, содержание; сортировка по дате
- **Фильтры** — по дате (период), автору, колонке, текстовый поиск (с задержкой 3 сек)
- **Создание письма** — форма с полями: номер, дата, тема, содержание, приложение, файлы
- **Редактирование** — двойной клик по строке открывает форму редактирования
- **Файлы** — прикрепляются к письму и загружаются на YouGile
- **Экспорт HTML** — копирование таблицы в буфер обмена
- **Экспорт CSV** — файл в папку `Экспорт`

## 6. AI-помощник по письмам

Доступен внутри модуля Письма (кнопка AI).

- Задайте вопрос по содержимому писем — AI выполнит RAG-поиск по локальной базе
- Можно загрузить файл (изображение, PDF, DOCX, TXT) — AI прочитает и ответит по его содержимому
- Кнопка **«Создать письмо»** в ответе AI — автоматически заполняет форму создания письма на основе ответа

Требуется настроить API ключ и URL в настройках плагина (блок Письма → AI помощник).

## 7. Экспорт в DOCX

Генерирует DOCX-файл письма по шаблону:

1. **Шаблон** — .docx файл с плейсхолдерами `{{Номер}}`, `{{Дата}}`, `{{Тема}}`, `{{Содержание}}`, `{{Текст}}`, `{{Приложение}}`, `{{Компания}}`, `{{Адрес}}` и т.д.
2. **Без шаблона** — fallback-генерация через библиотеку `docx` (стили, таблицы, изображения)

Изображения из письма вставляются в документ.

Путь к шаблону и папка экспорта настраиваются в блоке Письма → Экспорт в DOCX.

## 8. Календарь мероприятий

Открывается через ribbon-иконку с календарём или команду.

- **Месячный календарь** — просмотр задач на месяц с цветовой индикацией статуса
- **Детали дня** — клик по дню открывает список событий
- **Создание мероприятия** — форма с полями: название, место, аудитория, ответственный (email), дата/время, описание
- **Материнская задача** — при создании можно выбрать родительскую задачу (поиск по всем проектам/доскам через автодополнение):
  - Новая задача мероприятия автоматически становится подзадачей родителя (добавляется в `subtasks`)
  - Чекбокс **«Завершить материнскую задачу при завершении мероприятия»** — при завершении мероприятия родительская задача тоже завершается
  - **Проверка дедлайна** — если дата мероприятия выходит за пределы дедлайна материнской задачи, показывается предупреждение (создание не блокируется)
- **Отчёт о мероприятии** — форма с текстом и файлами, после отправки задача отмечается завершённой
- **Фильтры** — чекбоксы колонок, переключение «Все / Мероприятия / Документы»
- **Редактирование** — кнопка ✏️ в деталях события

Настройка: блок **Календарь** в настройках плагина (проект + доска).

## 9. Дашборд

Открывается через ribbon-иконку с графиком или команду.

- **4 графика** ApexCharts:
  - «Задачи по колонкам» (donut)
  - «Статус задач» (bar)
  - **«Динамика озадачивания»** (area) — две серии: «Поступило задач» / «Задач решено», пунктирные отсечки дедлайнов
  - «Дедлайны» (bar)
- **Метрики** — счётчики: всего задач, просрочено, завершено, с дедлайном
- **Фильтры**:
  - Проект, колонка, исполнитель — выпадающие списки
  - Период дат — поля `с ... по ...`
  - **«Учитывать подзадачи»** (чекбокс, выкл.) — исключает задачи, являющиеся подзадачами других
  - **«Показать дедлайны»** (чекбокс, вкл.) — отображает пунктирные линии на графике динамики
- **Ось X графика динамики** — от первой задачи в базе до сегодня (если не задан фильтр дат)
- **Экспорт JPG** (scale 2x) — каждый график отдельно или все сразу
- **Экспорт CSV** — таблица задач в файл

## 10. Экспорт данных

| Формат | Где доступен | Как работает |
|--------|-------------|--------------|
| HTML | Письма, Документы | Копирует таблицу в буфер обмена |
| CSV | Письма, Документы, Дашборд | Сохраняет файл в папку `Экспорт` с BOM, разделитель `;` |
| DOCX | Письма | Генерирует DOCX по шаблону или автоматически |
| JPG | Дашборд | Сохраняет скриншот дашборда (scale 2x) |

## 11. Горячие клавиши

Назначьте в Obsidian: **Настройки → Горячие клавиши → поиск «YouGile»**.

| Команда | ID |
|---------|-----|
| YouGile: Показать задачи | `yougile-tntn:create-task` |
| YouGile: Обновить список задач | `yougile-tntn:refresh-tasks` |
| YouGile: Открыть расписание мероприятий | `yougile-tntn:open-schedule` |
| YouGile: Открыть документы | `yougile-tntn:open-documents` |
| YouGile: Открыть письма | `yougile-tntn:open-emails` |
| YouGile: Открыть дашборд | `yougile-tntn:open-dashboard` |
